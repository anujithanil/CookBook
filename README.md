# CookBook

CookBook is a full-stack recipe sharing platform that enables users to discover, create, and organize recipes in one place. Users can upload recipes with images, search for dishes, interact with the community through comments, save their favorite recipes, and manage their personal recipe collection. The platform provides a simple and responsive interface for cooking enthusiasts to share and explore recipes.

## Features

- User registration and login
- Secure user authentication
- Browse recipes shared by other users
- Search recipes by name
- Upload recipes with images
- Edit and delete personal recipes
- Save and unsave favorite recipes
- View saved recipes
- View recipes uploaded by the logged-in user
- Comment on recipes
- Responsive and user-friendly interface
- Cloudinary integration for image storage

## How It Works

1. Users register and log in to their accounts.
2. Users can browse recipes shared by the community.
3. Recipes can be searched.
4. Users can upload new recipes along with images.
5. Images are stored securely using Cloudinary.
6. Users can comment on recipes to share feedback or suggestions.
7. Favorite recipes can be saved for quick access.
8. Users can edit or remove recipes they have uploaded.
9. Personal and saved recipes are accessible from dedicated pages.
